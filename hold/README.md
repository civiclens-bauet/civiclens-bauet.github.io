# CivicLens AI — Pro V2

Competition-focused frontend prototype for the IEEE/PROCON presentation.

## Theme
Black + Red + Blue. No lime/green primary theme.

## Run
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Use Live Server, or simply open `index.html`.
4. Start on Command Center.

## Best 3-minute demo
1. Command Center → show Civic Pulse, KPI cards, Live Situation Map and AI Priority Queue.
2. Click a red incident marker → explain the AI score.
3. Live Situation Map → switch MAP / HEAT / RISK layers and click Pond or Gate-2.
4. Report Issue → type: "Heavy rain has left water standing beside the pond..." → Analyze with CivicLens AI.
5. Show confidence, severity, priority and recommended department.
6. Create Verified Incident → Incident Operations.
7. Open Authority Center → show closed-loop response timeline.
8. AI Intelligence → ask Civic Copilot "What is the highest priority incident?"
9. Finish with the principle: "No report disappears into a form; every verified issue gets a priority, owner, status and closure evidence."

## Important
This is a polished frontend/demo prototype. The AI outputs are simulated locally for presentation. For a production system, connect the report form, database, GIS, authentication and actual ML/LLM services.
